# 使用虚拟化的连续话题阅读

话题以虚拟化的连续帖子列表呈现，并围绕成员由服务器确定的当前位置增量加载；原生时间线可按帖子编号或日期跳转。IntelliDo 不提供分页导航，预取或虚拟化内容只有满足真实可见性规则后才计为阅读。

新增、编辑、删除或修订的帖子可实时更新已打开的话题，但更新绝不会移动读者的视口。新内容显示在明确的 **新帖子** 指示器后，由读者主动触发向前导航；可见帖子的变化则原位合并，不抢夺焦点。

`Ctrl/Cmd+F` 打开作用于整个有权访问话题的原生“查找”栏，而不只搜索当前已虚拟化的帖子。IntelliDo 按需查询和加载匹配帖子、高亮结果并在结果间导航，但不在本地持久保存查找词。双击 Shift 仍是独立的全局“随处搜索”Action。
