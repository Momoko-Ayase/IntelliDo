# 明确标识 IntelliDo 为非官方客户端

IntelliDo 可以使用获准的 LINUX DO 品牌元素，但会在仓库、下载页、安装程序元数据、About 对话框和登录界面中标识自身为“非官方 LINUX DO 客户端 / Unofficial LINUX DO Client”。主窗口可以只使用简洁的 IntelliDo 产品名，而获取和身份边界负责防止用户误认为它是社区官方产品。

应用使用独立的 IntelliDo 图标和字标作为产品身份，而非直接使用 LINUX DO Logo。图标采用 IDEA 风格的几何设计，并使用 LINUX DO 的黑、白、黄色调；LINUX DO 品牌在产品内部仍作为社区上下文身份出现。

Nightly 构建在标题和 About 界面中显示 **IntelliDo Nightly**，并使用带明显角标的应用与托盘图标，避免被误认为稳定版。

首次启动的 Home 欢迎面板包含非官方客户端声明，但不阻塞匿名浏览。
