# 默认使用简体中文

无论系统区域设置为何，IntelliDo 在所有受支持操作系统上首次使用时都以简体中文启动。兼容的 JetBrains 语言包负责平台 UI 本地化，IntelliDo 自身捆绑简体中文和英文资源；缺失的中文字符串回退为英文，不进行运行时机器翻译。日后可安装其他兼容语言包，服务器提供的标签和社区成员创作的内容则保持 LINUX DO 原样。

IntelliDo 中文资源在话题、帖子、私信、信任等级和操作等方面遵循成员已在 LINUX DO 接触的术语。这些术语是经审查的词汇参考，并非远程载入的 UI 字符串；原生应用文案仍随 IntelliDo 捆绑并版本化。

更改应用语言时会明确提示重启，并在下次启动时原子应用，遵循标准 IntelliJ 语言包行为，避免实时会话处于部分翻译状态。

时间戳使用设备当前时区及所选 IntelliDo UI 区域设置。相对时间标签在 Tooltip 中显示准确的绝对日期、时间和时区；IntelliDo 不增加独立的时区设置。
