# 不收集产品遥测

IntelliDo 不收集产品分析、操作使用情况、浏览历史、阅读行为或后台遥测。本地故障排查日志生命周期短且大小受限，自动遮盖 Cookie、Token、内容正文、搜索词和敏感 URL 参数，并且默认绝不保留网络 Payload；成员可直接打开或清除日志。崩溃和诊断提交只能手动进行，传输前必须展示准确的已脱敏数据包；更新检查和 JetBrains Marketplace 访问属于功能性网络请求，而非分析。

普通支持和 Bug 报告提交至规范的 GitHub Issues。安全漏洞使用 GitHub 私密漏洞报告渠道，绝不能附加到公开 Issue。帮助和诊断预览同时展示两种目的地，并在打开任何公开报告前警告。

无遥测承诺涵盖 IntelliDo 及其捆绑组件。已安装的第三方插件以完整应用权限运行，可能具有 IntelliDo 无法保证的独立隐私政策、分析或网络行为；插件信任 UI 和隐私声明会披露该边界。
