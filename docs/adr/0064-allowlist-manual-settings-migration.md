# 通过允许列表手动迁移非敏感设置

IntelliDo 提供手动导出和导入设置的能力，作为不使用 JetBrains Settings Sync 或其他云同步服务时的可控设备迁移方式。归档只包含明确允许的非敏感设备设置，例如主题选择、Keymap、工具窗口布局和普通应用行为偏好。导出前必须展示准确内容清单，并允许成员取消。

设置归档永久排除 LINUX DO 与 Marketplace 身份、JCEF 配置和浏览器存储、Cookie 与 Token、代理凭据、通知预览和后台运行等账户敏感同意、日志、缓存、下载文件、第三方插件及其数据。导入过程只接受 IntelliDo 已知的设置类型，先校验归档，再原子应用；不兼容或未知字段会在预览中明确列出，而不能触发代码载入或覆盖受保护数据。

成员自行导出的设置归档属于明确下载到 IntelliDo 管理存储之外的文件，因此“清除所有本地数据”和卸载清理不会删除它。
