# JCEF 无法启动时采用封闭式恢复

JCEF 是 IntelliDo 登录、已验证与匿名社区传输、受信任应用内浏览以及身份安全页面的必要安全边界。若 JCEF 初始化失败，IntelliDo 不进入 Home，也不提供降级匿名浏览，而是只显示最小原生恢复界面。

恢复界面提供已脱敏的诊断摘要、**重试初始化**、**打开修复说明**、**复制诊断信息** 和 **退出**。修复说明在可用时优先打开本地捆绑文档；若成员明确选择在线说明，则交给系统浏览器。界面不能展示账户内容、载入第三方插件或启动后台通知模式。

IntelliDo 绝不因 JCEF 故障临时切换到 JVM HTTP 客户端、系统浏览器会话抓取或其他替代传输。这些路径会绕过既定 Cookie、CSRF、Cloudflare、会话清理和单账户边界。恢复只能修复或重新初始化同一 JCEF 架构；无法恢复时安全退出。
