# 原生渲染标准社区目录

初始原生核心包括分类、标签、群组、徽章和成员目录及其详情视图。它呈现服务器授权给普通成员的所有操作，包括在 LINUX DO 允许时加入、退出或申请加入群组。可见性和操作继续由服务器能力数据与 IntelliDo 永久的 Level 3 上限共同管理；这些标准路由不能仅因位于话题之外就回退到应用内浏览器。

服务器允许的普通成员邀请管理也采用原生实现：创建邀请链接或邮件邀请、查看待处理与已兑换邀请，以及撤销邀请。仅限管理员的邀请配置和批量工具仍超出能力上限。

标准社区信息路由——About、FAQ 或指南、条款、隐私以及公开工作人员或联系列表——在 LINUX DO 提供受支持结构化契约时原生渲染。没有该契约的路由使用受限应用内浏览器。**已阅读指南** 等任何服务器端确认状态仍以服务器为权威。
