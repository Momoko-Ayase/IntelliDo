# 原生渲染帖子内容

IntelliDo 将 Discourse 的 cooked 帖子内容解析为原生文档模型，并使用 IntelliJ 或 Swing 组件渲染受支持的文本、链接、引用、列表、代码、图片、表格、折叠内容、Onebox、投票和插件区块。话题或帖子正文不使用 JCEF 渲染；未知元素在其自身组件范围内显示原生错误占位。为保留核心原生体验，项目接受较大的渲染器工作量。围栏代码块使用只读 IntelliJ 编辑器组件，支持按语言高亮、选择、复制、行号和软换行，但不提供任何执行操作。激活图片时打开原生灯箱，支持缩放、平移、原始尺寸、适应窗口、复制和明确的保存操作；动画格式可使用原生解码，不支持的媒体保留预览以及明确的外部打开或下载操作。个别交互式嵌入可作为隔离的 JCEF 内容岛存在，但不得共享已验证身份的 LINUX DO 会话、调用原生桥接、访问本地资源或控制应用导航；离开嵌入的链接在系统浏览器中打开。

嵌入内容岛不能请求摄像头、麦克风、位置、屏幕捕获或广泛的剪贴板权限。

每个帖子嵌入内容岛使用与受信任身份验证浏览器配置隔离的临时 Cookie 和 Web 存储。包含它的话题关闭或 IntelliDo 退出时，其状态即被丢弃，避免普通嵌入建立跨话题的持久跟踪档案。

由 LINUX DO 配置的上传和 CDN 来源提供的媒体可正常加载。其他来源的图片或媒体均保留在原生 **仅加载一次** 占位后；只有明确激活后才会在不携带 Cookie 和 Referrer 的情况下获取。IntelliDo 不保存持久的第三方媒体允许列表。

折叠内容、模糊媒体以及服务器标记的敏感或 NSFW 内容默认保持隐藏。揭示状态仅对当前话题视图有效，不会持久化，也不会提供缩略图或外部通知预览。

cooked HTML 解析器在创建原生组件前使用严格的元素、属性和 URL Scheme 允许列表。即使内容来自服务器，脚本、内联事件处理器、任意样式、不安全 URL 及其他可执行标记也会被移除；内容权威性不等于对客户端执行能力的信任。

上传的 SVG 只有在禁用脚本和外部引用并安全栅格化后才能内联显示。不安全或不受支持的 SVG 保留为明确的下载占位，绝不会作为活动文档载入 JCEF。

音频、视频和交互式嵌入永不自动播放。动画图片遵循操作系统的减少动态效果设置，并提供原生暂停控制。
