# 应用偏好仅保存在本地

IntelliDo 的主题、Keymap、布局及其他应用偏好只保存在当前安装中。它不集成 JetBrains Settings Sync，不使用 JetBrains 账户同步偏好，也不引入 IntelliDo 或第三方同步服务器。LINUX DO 社区偏好继续由服务器管理，不复制到本地偏好存储。

为购买 Marketplace 内容和激活付费插件许可证而进行的可选 JetBrains 身份验证，是仅限许可用途的窄例外。它不能启用 Settings Sync，也不能传输 IntelliDo 偏好。

退出登录会保留设备外观与交互偏好，例如主题、Keymap 和工具窗口布局。在替换身份获准登录前，会重置账户敏感的本地选择，包括通知预览同意、通知暂停状态、登录时启动与后台同意，以及所有会话范围的受信任浏览器权限。
