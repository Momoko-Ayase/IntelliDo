# 使用 IntelliJ 主题生态

IntelliDo 使用原生 IntelliJ Platform 主题体系，不复刻 LINUX DO 网站主题。成员可通过 JetBrains Marketplace 或本地插件包安装兼容的免费或付费主题插件，使外观可扩展，而不把核心界面变成 Web UI。

成员可选择仅为 Marketplace 购买和付费插件许可证激活而登录 JetBrains。该身份验证不会启用 JetBrains Settings Sync，也不会创建另一个 IntelliDo 产品身份。

退出 LINUX DO 不会退出 Marketplace 身份，也不会撤销已安装的付费主题许可证。Marketplace 身份验证有独立、明确的退出控制。

话题阅读提供设备本地的正文字体、字号、行距和最大内容宽度设置，与编辑器及代码编辑器字体分开。这些设置仍继承 IntelliJ 缩放比例和当前应用主题。
