# 阅读活动仅以服务器记录为准

IntelliDo 不维护已读话题、帖子或时长的持久本地账本。它只向 LINUX DO 报告真实的登录后阅读活动，并使用服务器返回的状态，因此匿名或离线活动永远不会被补报为升级进度，产品也不会偏离社区的权威记录。

原生状态栏只显示当前连接、身份验证和上报状态，例如 **正在阅读**、**空闲** 或 **离线**。它不显示本地估算的分钟数、帖子数或升级进度；数值进度只属于 Connect 或明确标注的低等级估算。

如果 LINUX DO 拒绝或无法确认阅读更新，状态栏将切换为警告状态，并明确说明受影响时段未被记录。IntelliDo 不会声称获得该时段的进度，也不会事后补报。

匿名浏览转为登录状态后，只有身份验证成功之后产生的真实注意力才开始上报。登录前已查看的内容永远不会被补记到账户阅读活动中。
