# 通过隔离的已验证身份适配器解析 Connect

在 LINUX DO Connect 提供稳定的详细进度 API 前，IntelliDo 通过现有 JCEF 传输载入其已验证身份页面，并在隔离适配器后只解析已知状态字段。解析数据必须通过严格结构验证才能原生渲染；任何契约变化都产生 Connect 专属兼容性错误，而不是展示过期、残缺或推断出的权威状态。刷新发生在工具窗口打开、明确请求，以及窗口可见时每五分钟一次；并发请求会合并，同时遵守服务器限流或退避要求。Connect 不持久保存进度快照，也不生成通知；信任等级提升提醒仍由 LINUX DO 负责。

该适配器是 IntelliDo 唯一获准的渲染页面 DOM 解析器。所有其他原生功能都必须依赖结构化服务器响应。
