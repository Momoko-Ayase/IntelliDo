# 将已验证身份的应用保留在托盘中

IntelliDo 可选择隐藏窗口，并利用现有已验证身份的 JCEF 上下文保持精简托盘状态以接收通知。它不会创建独立守护进程或导出会话材料；后台模式必须在 IntelliJ Platform 和 JCEF 允许范围内释放非活跃 UI 资源并暂停无关工作，同时接受其无法像基于 Token 的原生辅助进程一样轻量。独立的登录时启动选项默认关闭；启用后，IntelliDo 直接进入后台模式，不打开主窗口。

启用后台模式时，关闭主窗口会把 IntelliDo 隐藏到托盘，明确执行 **退出** 才会结束进程。未启用后台模式或操作系统没有可用托盘时，关闭窗口会正常退出。首次发生隐藏行为时，IntelliDo 只解释一次。

托盘菜单仅包含 **显示 IntelliDo**、不含元数据的未读数量、**暂停/恢复通知**、**退出登录** 和 **退出**。它永不显示话题标题、作者、消息预览或快速回复操作。

**暂停通知** 只抑制操作系统通知。与 LINUX DO 的直接连接保持活跃，汇总未读数量继续更新，服务器偏好和已读状态不变。

暂停状态是本地应用偏好，会跨重启保留，直到成员明确恢复通知。

如果登录时启动在后台模式下发现记住的会话已过期，IntelliDo 不抢夺焦点，也不自动打开 JCEF。它只显示私密的 **需要登录** 操作系统通知；成员激活该通知后才打开登录页。

明确退出登录会禁用登录时启动，因为匿名后台模式没有账户通知可接收。之后再次成功登录时可以询问是否恢复该选项，但绝不自动启用。
