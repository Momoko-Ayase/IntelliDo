# 搜索私密对话必须明确选择范围

“随处搜索”的默认“全部”范围包含 Action、设置、分类、标签、成员以及有权访问的普通话题和帖子，但不包含私信或 Chat 文本。搜索私密对话必须主动选择“私信”或“Chat”范围，既防止敏感内容意外出现，又保留完整的可搜索能力。

当 LINUX DO 搜索返回服务器标记为敏感或 NSFW 的普通话题时，它们仍位于默认“全部”范围；IntelliDo 不增加客户端专属的“敏感”范围或排除规则。明确选择范围的例外只适用于私信和 Chat。

把规范的 `https://linux.do/...` URL 粘贴到“随处搜索”时，IntelliDo 会识别受支持路由并导航至对应的原生目标。初始版本不注册自定义 `intellido://` 协议，也不尝试成为操作系统的浏览器链接处理程序。

普通话题和帖子搜索接受完整的 Discourse 搜索语法。IntelliDo 为已知的分类、标签、成员、日期、状态和排序操作符提供补全，但解析和权威结果仍属于 LINUX DO；未知或新引入的操作符保持原样传递，不会被本地拒绝。
