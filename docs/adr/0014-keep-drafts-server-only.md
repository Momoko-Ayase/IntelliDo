# 草稿仅保存在服务器

IntelliDo 通过 Discourse 的服务器草稿机制自动保存已登录成员的草稿，两个自动保存点之间的编辑仅保留在内存中。它不维护本地或离线草稿存储，从而与 LINUX DO 保持连续性，并避免为可能私密的未发布内容建立第二份持久存储；代价是可靠恢复必须保持连接。关闭包含比最近一次自动保存更新内容的编辑器时，将立即触发服务器保存；保存失败会阻止普通关闭，只提供重试或明确丢弃。

草稿修订号或顺序冲突通过编辑器的原生冲突视图解决，而不是采用后写覆盖。

原生“草稿”工具窗口列出成员的服务器草稿，并支持继续编辑和明确删除。继续草稿时创建或聚焦对应的编辑器标签页；列出草稿不会产生持久本地副本。

如果 Chat 或 Boost 没有提供服务器草稿契约，其未发送输入只存在于内存中，并在相应视图关闭或 IntelliDo 退出时丢失。关闭非空输入前必须明确确认丢弃；IntelliDo 不为 Chat 或 Boost 建立本地草稿例外。
