# 操作系统通知默认保持私密

所有 IntelliDo 操作系统通知默认隐藏作者、话题标题、分类、标签、消息类型和内容摘要，因为即使名义上公开的话题也可能受访问控制或包含敏感内容。已验证身份的“通知”工具窗口可以显示完整细节，其已读和未读状态以服务器为权威；IntelliDo 不维护并行的本地通知状态。成员可以明确选择启用更丰富的外部预览。操作系统通知只用于导航：激活后在 IntelliDo 中打开准确且有权访问的目标；回复、回应及已读状态更改仍留在已验证身份的原生 UI 中。

预览授权按类型细分：普通话题、私信和 Chat 各自需要单独选择启用。即使已启用普通话题预览，受访问限制或服务器标记为敏感、NSFW 的话题通知仍不包含元数据。

打开“通知”工具窗口不会清除或确认其中内容。选择通知时按照 LINUX DO 的服务器行为进行确认；**标为已读** 和 **全部标为已读** 是明确的服务器端操作。

初始版本不增加静默时段调度器。LINUX DO 服务器偏好决定哪些通知符合条件，操作系统的“勿扰”或“专注”控制决定是否显示外部通知。

托盘菜单遵循同一隐私边界，只可选择显示汇总未读数量，绝不显示通知元数据或内容操作。

托盘中的本地暂停控制只抑制操作系统通知，不修改服务器通知偏好或未读状态。
