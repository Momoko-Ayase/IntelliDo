# 使用单一主窗口和标签式内容区

IntelliDo 只呈现一个应用窗口，其中包含一个标签式内容区和配套工具窗口，不存在 IDEA 项目窗口或多个独立 Frame。Home 是永久且不可关闭的第一个标签页；调用 Home 时聚焦并刷新这唯一实例。话题采用 IDEA 风格的预览语义打开：普通激活复用一个预览标签页，明确固定或替代激活会使其持久化，回复、编辑或其他有意义的交互会自动固定它。LINUX DO Connect 位于持久工具窗口中，使升级状态可在全局访问，而不是像内容一样被打开。“私信”工具窗口充当收件箱，并在内容标签页中打开私信话题；Chat 完整保留在其实时工具窗口中。专用“通知”工具窗口显示服务器提供的未读状态和类型筛选，并导航至准确且有权访问的话题、帖子、私信或 Chat 项。“书签”工具窗口显示成员保存在服务器上的话题和帖子，提供筛选、提醒时间以及服务器端编辑、删除和提醒操作；它不建立并行的本地收藏存储。“草稿”工具窗口列出服务器草稿，并在对应编辑器标签页中恢复草稿，不建立持久本地草稿存储。“后退”“前进”和“最近位置”只在当前已登录进程的内存中保留准确锚点，退出登录或退出应用时清除。打开的标签页及其路由不会跨启动恢复；每次启动都从 Home 开始。

从匿名模式明确登录时，已打开的公开标签页会保留，并按已验证身份后的能力集合重新获取。此前的匿名浏览不会转化为服务器阅读活动。

明确退出登录会关闭除 Home 外的全部标签页，包括公开话题，清除内存中的“后退”“前进”和“最近位置”历史，并返回匿名 Home。

每个话题最多存在一个标签页，私信话题也一样。导航到已打开话题中的其他帖子时，会聚焦现有标签页并移动到请求的锚点，同时把先前锚点记录到内存导航历史，而不是打开重复标签页。

初始版本只有一个内容标签组，不支持水平或垂直编辑器拆分。工具窗口是唯一可同时显示的辅助视图，使阅读注意力与编辑器归属保持明确。

首次启动直接打开 Home，并可显示可关闭的原生欢迎面板，包含登录、非官方客户端说明、隐私和关键快捷键。IntelliDo 不提供阻塞式引导向导。
