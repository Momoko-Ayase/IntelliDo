# 最近内容搜索保存在服务器

IntelliDo 读取并更新 LINUX DO 保存的五项最近搜索历史，不持久保存自己的查询历史。只有普通、由服务器支持的话题和帖子搜索参与其中；Action 名称、设置、私信查询和 Chat 查询均被排除，除非对应上游功能日后独立定义服务器历史。

“随处搜索”提供 **清除最近搜索**，经确认后通过 LINUX DO 删除这五项记录。由于不存在本地查询历史，服务器成功删除即完成操作。

Discourse 会记录完整搜索页和页头搜索请求，并公开最近若干个不同的已记录词条，但不提供按请求跳过历史的受支持选项。因此，IntelliDo 对渐进式远程话题、帖子搜索进行防抖，并完全接受 LINUX DO 所记录的历史。它绝不会为了移除部分查询而先清空再重建历史，因为这可能抹去成员在网站上完成的搜索。

如果 LINUX DO 禁用搜索日志或拒绝访问最近搜索，IntelliDo 将同时隐藏历史区和清除操作。这不属于应用错误，也绝不会启用本地后备历史。
