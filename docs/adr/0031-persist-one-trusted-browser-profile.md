# 持久保存一个受信任浏览器配置

IntelliDo 跨应用重启持久保存专用 JCEF 配置，使唯一的 LINUX DO 账户保持登录，直到服务器令会话过期或成员退出登录。可复用的持久会话机密必须使用操作系统保护的凭据存储；若不可用，IntelliDo 会警告成员并使用仅限进程生命周期的配置，而不会写入未受保护的机密。退出登录会清除 LINUX DO、Connect、受信任服务以及身份验证期间访问过的外部 Origin 的 Cookie 和 Web 存储，停止后台模式，关闭账户范围标签页，并返回匿名 Home。第二个账户配置不能共存。

从未登录过的匿名会话仅在当前进程中保留其 JCEF Cookie 和 Web 存储。只有成功完成身份验证后，IntelliDo 才把专用配置提升为受保护的持久存储。

普通的已退出登录启动会打开匿名 Home，并等待明确的登录操作。若 IntelliDo 检测到此前记住的已验证会话已经过期，则自动打开 LINUX DO 登录页，使成员可以立即恢复中断的会话，而不是被静默降级为访客浏览。

自动重新验证身份可以取消。取消后返回匿名 Home，并在本次启动剩余期间抑制后续自动提示；成员仍可明确调用 **登录**。

若会话在 IntelliDo 运行期间过期，仅限账户的视图立即锁定并要求重新验证身份，公开视图仍可使用。成功重新验证后解锁现有内存视图；取消则清除已锁定的私密视图并返回匿名 Home。即使普通持久会话预期长期有效，也保留该防御性路径。

若重新验证时使用了不同用户名，必须先执行完整的单账户替换边界，才能向原生视图暴露新身份。

从 LINUX DO 身份或安全页面退出登录，会被识别为与 IntelliDo 原生 **退出登录** 相同的操作，并立即执行完整清理边界。

该清理会关闭包括公开话题在内的所有非 Home 标签页，清除全部内存导航历史，并返回匿名 Home，避免账户时期的内容在退出登录后继续可见。

自动重新验证页面只适用于交互式启动。登录时启动的后台模式若发现会话过期，只生成私密的 **需要登录** 操作系统通知；激活通知后才打开登录页。

初始版本不提供 IntelliDo 专属 PIN、密码或生物识别应用锁。它依赖操作系统用户会话锁和 IntelliDo 完整的 **退出登录** 边界，而不引入第二套本地凭据系统。

退出登录只保留设备级外观和交互偏好。通知预览同意、通知暂停状态、后台与自动启动同意以及受信任浏览器权限授权，都会在其他账户登录前重置。

独立且可选的 JetBrains Marketplace 身份及其插件许可证不属于 LINUX DO 退出登录范围，并使用单独的 Marketplace 退出操作。
