# 跟随 IntelliJ Platform 的操作系统支持范围

IntelliDo 支持 Windows x64、Linux x64、macOS x64 和 macOS Apple Silicon。每个 IntelliDo 稳定版的最低操作系统版本跟随其捆绑的 IntelliJ Platform 与 JetBrains Runtime 基线，而不是独立冻结一项旧系统支持承诺。提供更新前，发布说明和下载页必须列明该版本准确的最低 Windows、macOS 和 Linux 版本。

每个 IntelliDo 稳定版面向一个特定的稳定 IntelliJ Platform 基线。项目只维护一条当前稳定线，不为旧基线并行维护长期支持分支；后续 IntelliDo 版本会审慎采用更新的平台基线。

实现从当时能够通过 JCEF、兼容主题、语言包和打包可行性检查的最新稳定平台基线开始。IntelliDo 不以 IntelliJ EAP 基线作为产品基础。
