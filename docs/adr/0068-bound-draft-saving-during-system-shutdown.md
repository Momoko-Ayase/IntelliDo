# 操作系统关机期间限制草稿保存

操作系统请求注销或关机时，若已验证身份的编辑器含有未同步内容，IntelliDo 只进行一次具有严格短超时的 LINUX DO 服务器草稿保存尝试。保存成功后，内容按普通服务器草稿恢复；保存失败、超时、断网或会话过期时，IntelliDo 不重试到阻塞系统，也不延迟操作系统完成注销或关机。

该路径绝不创建本地草稿、恢复文件或待重放写入，也不在下次启动自动提交内容。异常退出提示只能引导成员查看最后一次实际成功同步的服务器草稿，并明确说明两次服务器保存之间的内存编辑可能已经丢失。

该限制只适用于操作系统主导、无法可靠等待交互的终止流程；成员在 IntelliDo 中明确关闭编辑器或退出应用时，继续使用可交互的保存、重试、复制和明确丢弃边界。
