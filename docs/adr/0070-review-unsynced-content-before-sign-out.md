# 退出登录前检查未同步内容

成员明确选择 **退出登录** 时，IntelliDo 在清除账户数据前运行原生的未同步内容汇总检查。具有服务器草稿契约的帖子和话题编辑先尝试保存至 LINUX DO；Chat 与 Boost 等仅内存输入必须逐项复制或明确丢弃。任何服务器保存失败都允许重试，成员也可以取消整个退出登录操作并返回原会话。

该检查不能把仅内存内容转化为本地草稿，也不能在成员确认退出登录后继续后台保存。一旦所有内容成功保存或被明确丢弃且成员最终确认，IntelliDo 立即执行完整退出登录边界：停止后台模式、清除账户与浏览器会话数据、关闭所有非 Home 视图、清除内存导航和编辑缓冲区，并返回匿名 Home。

从 LINUX DO 身份或安全页面检测到的 Web 退出登录同样需要处理未同步内容。IntelliDo 先锁定账户写入并显示该检查；由于服务器会话可能已失效，无法保存的项目只提供复制、明确丢弃或取消后重新登录，而不能假装已保存。
