# 主动退出前检查所有未同步内容

成员明确选择 **退出 IntelliDo** 时，若任何帖子编辑器、Chat 或 Boost 视图含有未同步输入，IntelliDo 显示一个原生汇总检查界面，并列出每项内容的类型、目标和保存能力。服务器支持草稿的帖子或话题编辑器先尝试保存到 LINUX DO；保存失败时提供 **重试**、**取消退出** 或对该项 **明确丢弃**。

没有服务器草稿契约的 Chat 与 Boost 输入绝不建立本地副本。成员可以逐项复制纯文本或明确丢弃；仍有未解决项目时不能完成普通退出。汇总界面不得显示隐藏或敏感内容的正文预览，只显示足以识别编辑目标的私密原生元数据。

成员取消后返回原有视图，内存输入保持不变。只有所有项目成功保存或被明确丢弃后才结束进程。该交互式流程不适用于操作系统主导的注销、关机、崩溃或强制终止；那些情况继续遵循受限保存或内存丢失边界。
