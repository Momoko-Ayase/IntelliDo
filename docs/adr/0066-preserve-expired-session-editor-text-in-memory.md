# 会话过期时只在内存中保护编辑文本

若 LINUX DO 会话在编辑器含有尚未同步的文本时过期，IntelliDo 立即锁定编辑器和所有写入操作，但在当前进程内保留编辑缓冲区。成功重新验证同一身份后，先重新获取服务器草稿和资源能力；没有冲突时继续编辑，存在变化时进入既有原生冲突流程，绝不自动提交缓冲区。

若成员取消重新登录，IntelliDo 在执行私密视图清理前显示一次原生确认，提供 **复制文本** 和 **明确丢弃**。复制只把成员选择的纯文本放入系统剪贴板，不建立本地文件或草稿；确认结束后，缓冲区随其他私密内存状态清除并返回匿名 Home。

进程崩溃、被终止或设备断电时，该内存缓冲区不能恢复。只有此前成功同步到 LINUX DO 的服务器草稿具有持久恢复能力。
