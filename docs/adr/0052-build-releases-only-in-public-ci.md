# 只在公开 CI 中构建发布产物

每个 IntelliDo 稳定版产物及其公布哈希，都由 GitHub Actions 根据受保护的语义化版本 Tag 生成。维护者本地构建的二进制绝不加入稳定版。无论定时触发还是手动调度，Nightly 构建都使用同一公开 Workflow，使每份产物持续关联至源代码 Commit 和可见构建日志。这在操作系统代码签名不可用时提供可审计来源，同时不把哈希验证夸大为发布者身份验证。

除产物、哈希、源代码 Tag 和第三方声明外，稳定版 Workflow 输出还包含机器可读的 SPDX 或 CycloneDX SBOM。Nightly 构建初期可以不提供 SBOM。

逐位可复现的产物是有文档记录的项目目标，并配有公开验证说明。可复现性不阻塞首个稳定 `0.x` 里程碑；一旦所选 IntelliJ 打包工具链能够可靠生成确定性输出，它就成为发布门槛。
