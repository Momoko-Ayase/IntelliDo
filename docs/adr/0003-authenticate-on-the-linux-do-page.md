# 在 LINUX DO 页面完成身份验证

IntelliDo 将在内嵌浏览器中呈现 LINUX DO 的真实登录流程，不实现原生用户名或密码输入框。身份验证边界有意允许使用 Web UI，使 OAuth、Passkey、MFA、登录挑战及未来身份机制的变化继续由 LINUX DO 负责，同时保持应用核心体验原生化。

只有当成员在 LINUX DO 登录页主动发起操作时，外部 OAuth 提供方才可在临时身份验证模态视图中打开。该视图始终显示准确来源，不具备原生桥接能力，并且必须返回 LINUX DO 才能完成身份验证；无关导航将转交系统浏览器。

如果 JCEF 无法在当前平台完成某种身份验证方式，IntelliDo 将显示明确的兼容性错误，并允许成员重试 LINUX DO 提供的其他方式。它绝不会从系统浏览器导入 Cookie，也不会以原生凭据输入框作为后备方案。
