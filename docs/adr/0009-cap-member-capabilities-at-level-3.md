# 将成员能力上限设为 3 级

IntelliDo 将实现 LINUX DO 信任等级 0 至 3 的普通成员能力，并永久排除需要 4 级、版主或管理员权限的原生操作。权限更高的账户仍可登录，但 IntelliDo 原生界面只公开 3 级成员能力；工作人员和社区治理流程保留在网站中。

该上限只适用于 IntelliDo 原生工具，不限制网站访问。任何不受原生支持的 `https://linux.do/` 路由，包括账户有权访问的 4 级、版主或管理员页面，都可继续通过受限的应用内浏览器访问；IntelliDo 不会把这些网页重新解释为原生支持能力。

成员可以原生提交举报，并查看服务器提供的本人举报历史及结果。审核队列、分配、处理及其他仅工作人员可用的控制仍被排除，即使已登录账户可在网站中访问它们。
